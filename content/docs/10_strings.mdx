String (`qoraal`) waa taxane xarfo Unicode ah. Adeegso xigasho labalaab
(`"..."`) ama mid keliya (`'...'`). String interpolation iyo escape sequences
lama taageero; `+` ayaa isku xira qiimayaasha. Hababka strings-ku waxay soo
celiyaan qiimayaal cusub, mana beddelaan qoraalka asalka ah.

## Abuurid, dherer iyo indexing

<SoplangCodeWindow title="strings_unicode.sop" code={`qoraal magac = "Ayaan"
qor("Salaan, " + magac)    // Salaan, Ayaan
door qoraalka = "Aé🙂"
qor(qoraalka.dherer())     // 3
qor(qoraalka[1])           // é
qor(qoraalka[-1])          // 🙂
qor(qoraalka.hore())       // A
qor(qoraalka.dambe())      // 🙂
qor(qoraalka.hel(9, "?"))  // ?`}/>

Boosasku waxay tiriyaan Unicode scalar values, ma aha UTF-8 bytes ama xarfo
isku dhafan (grapheme clusters). Index taban wuxuu ka tiriyaa dhammaadka.
Index maqan, `hore()` ee string madhan iyo `dambe()` ee string madhan waxay
soo celiyaan `maran`. `dherer(text)` iyo `text.dherer()` labaduba waa sax.

## Jarid iyo raadin

| Habka | Shaqada |
| --- | --- |
| `hel(index, default?)` | Hel hal xaraf ama qiimaha beddelka ah |
| `jar(start?, end?)` | Soo celi qayb; xadka dambe kuma jiro |
| `leeyahay(sub)` | Hubi in qoraal ku jiro |
| `bilow(sub)` | Hubi bilowga |
| `dhammaad(sub)` | Hubi dhammaadka |
| `raadi(sub, direction?)` | Soo celi index-ka koowaad ama kii dambe; `-1` marka la waayo |
| `tiri(sub)` | Tiri isku-aadyada aan is dul saarnayn |

<SoplangCodeWindow title="strings_search.sop" code={`door qoraalka = "moos iyo moos"
qor(qoraalka.jar(0, 4))        // moos
qor(qoraalka.jar(-4))          // moos
qor(qoraalka.raadi("moos"))    // 0
qor(qoraalka.raadi("moos", "dambe")) // 9
qor(qoraalka.raadi("canbe"))   // -1
qor(qoraalka.tiri("moos"))     // 2`}/>

`jar()` wuxuu aqbalaa xadad tiro dhan ah. Xadad ka baxsan qoraalka waa la
xaddidaa, xadad is rogayna waxay keenaan `""`. `raadi()` wuxuu aqbalaa
`"hore"` ama `"dambe"` marka jiho la siinayo. `tiri("")` waa khalad.
Xusuusnow: raadin liis ka maqan waxay soo celisaa `maran`, raadin string
ka maqanina waxay soo celisaa `-1`.

## Nadiifin iyo beddelid

| Habka | Shaqada |
| --- | --- |
| `masax(direction?)` | Ka saar bannaanada labada gees ama `"hore"` / `"dambe"` |
| `weynee()` | U beddel xarfo waaweyn iyadoo la raacayo Unicode |
| `yaree()` | U beddel xarfo yaryar iyadoo la raacayo Unicode |
| `beddel(old, new, count?)` | Beddel isku-aadka koowaad, tiro la cayimay ama dhammaan |
| `kuceli(count)` | Ku celi string-ka tiro jeer |

<SoplangCodeWindow title="strings_transform.sop" code={`door qoraalka = "  Salaan  "
qor(qoraalka.masax())          // Salaan
qor(qoraalka.masax().weynee()) // SALAAN
qor("MOOS".yaree())            // moos
qor("aa-aa".beddel("a", "x"))  // xa-aa
qor("aa-aa".beddel("a", "x", 2)) // xx-aa
qor("aa-aa".beddel("a", "x", maran)) // xx-xx
qor("ha".kuceli(3))            // hahaha`}/>

`beddel()` ee laba dood leh wuxuu beddelaa isku-aadka koowaad. Doodda
saddexaad waxay noqon kartaa tiro dhan oo aan tabanayn ama `maran` oo
beddelaysa dhammaan. `0` waxba ma beddelo. `kuceli()` wuxuu aqbalaa tiro
dhan oo aan tabanayn.

## Kala qaybin iyo isku xirid

`qeybi(separator)` wuxuu soo celiyaa liis strings ah. `xiriiri(values)` wuxuu
qiimayaasha liiska isugu xiraa string-ka loo adeegsaday kala-soocaha.

<SoplangCodeWindow title="strings_split_join.sop" code={`door magacyo = "Ayaan,Bilan,Hodan".qeybi(",")
qor(magacyo)                  // [Ayaan, Bilan, Hodan]
qor(" iyo ".xiriiri(magacyo))  // Ayaan iyo Bilan iyo Hodan
qor(", ".xiriiri([1, run, maran])) // 1, run, maran`}/>

Magacyada cusub waxaa lala wadaagaa hawlaha kale ee luqadda. Magacyadii hore
ee la taageero waxaa lagu qoray [tixraaca](/docs/14_keywords-reference#compatibility-spellings).
