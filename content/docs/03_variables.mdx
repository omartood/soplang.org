# Soplang Variables

Soplang variables waxaa lagu qeexaa erayo Somali-first ah oo ka tarjumaya doorka ama nooca. Tani waxay ka dhigtaa koodhka mid muujin leh oo u fudud barayaasha Af-Soomaaliga.

## Dynamic Variables – `door`

`door` waa soo gaabinta _doorsoome_ oo loo adeegsado doorsoomayaal _dynamically typed_.

**dynamic_variables.sop**

<SoplangCodeWindow title="dynamic_variables.sop" code={`door magaca = "Aamina"
door da = 19
door xaqiiqo = run`}/>

Doorsoome `door` ah wuxuu qaadan karaa qiime nooc kasta ah, xitaa marka dambe:

<SoplangCodeWindow title="dynamic_reassign.sop" code={`door x = 10
x = "hadda waa qoraal"   // waa la oggol yahay
qor(x)`}/>

### Declare Once

Magac waxaa la qeexi karaa hal mar oo keliya — xitaa gudaha block (`haddii`, `intay`, …). Si aad qiimaha u beddesho, ha ku celin `door`; si toos ah u qor `magac = qiime`.

<SoplangCodeWindow title="declare_once.sop" code={`door a = 1
a = 2          // sax: beddelid
door a = 3     // Khalad nooc: Magaca 'a' mar hore ayaa la qeexay [E020]`}/>

### Type Checking

Doorsoome nooc leh wuxuu xafidaa noociisa. Khaladaadka la ogaan karo waxaa qabta falanqaynta ka hor fulinta; qiimayaasha dynamic-ka ahna waxaa la hubiyaa marka la qoro. Qoraal aan sax ahayn wuxuu reebaa qiimihii hore. Jajab tiro dhan ah waa loo rogi karaa `abn`; jajab leh qayb tobanle ah lama aqbalo.

<SoplangCodeWindow title="static_type_error.sop" code={`abn tirada = 10
tirada = 20            // sax: weli waa abn
tirada = "labaatan"    // Khalad nooc: 'tirada' waa abn laakin qiimaheeda 'qoraal' ma ahan abn [E022]`}/>

Haddii aad rabto in doorsoome kasta uu yeesho nooc cad, isticmaal `soplang --strict file.sop`. Strict mode wuxuu diidaa `door`. Eeg [CLI & REPL](/docs/19_cli-and-repl).

## Constants – `madoor`

`madoor` (soo gaabinta _madoorsoome_) wuxuu mamnuucaa in doorsoomaha qiime cusub loo qoondeeyo. Liis ama walax uu hayo weli waxaa beddeli kara hababka wax beddela; ma aha xannibaad qoto dheer oo xogta oo dhan ah.

**constants_basic.sop**

<SoplangCodeWindow title="constants_basic.sop" code={`madoor magaca = "Soplang"`}/>

Constants lama u wareejin karo (reassign):

**constants_reassign_error.sop**

<SoplangCodeWindow title="constants_reassign_error.sop" code={`madoor luqad = "Somali"
luqad = "English"  // Khalad nooc: Ma bedeli kartid qiimaha doorsamaha madoor 'luqad' [E020]`}/>

`madoor` waxaa sidoo kale lagu dari karaa nooc static ah, si nooca qiimaha loo hubiyo:

**constants_typed.sop**

<SoplangCodeWindow title="constants_typed.sop" code={`madoor abn SANAD = 2025
madoor PI = 3.14159
qor(SANAD)`}/>
