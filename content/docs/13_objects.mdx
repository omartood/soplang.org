Walax (`walax`) waxay kaydisaa lammaanayaal fure iyo qiime ah. Furayaashu waa
qoraal, qiimayaashuna waxay noqon karaan nooc kasta. Fure waxaa loo qori karaa
magac caadi ah ama qoraal xigasho ku jira.

## Abuurid iyo gelitaanka qiimayaasha

<SoplangCodeWindow title="objects_access.sop" code={`walax qof = {magac: "Ayaan", da: 25}
qor(qof.magac)               // Ayaan
qor(qof["da"])               // 25
door fure = "magaalo"
qof[fure] = "Hargeysa"
qor(qof.hel(fure))           // Hargeysa
qor(qof.hel("shaqo", "ma jiro")) // ma jiro
qor(qof.dherer())            // 3`}/>

Dot-notation iyo bracket-notation labaduba way akhriyaan oo qoraan.
`hel(key, default?)` wuxuu isticmaalaa qiimaha beddelka ah keliya marka fure
maqan yahay. Qiime `maran` ah oo fure jira leeyahay weli waa `maran`.
Akhrinta fure maqan waxay soo celisaa `maran`.

## Hababka la wadaago

| Habka | Natiijada |
| --- | --- |
| `dherer()` | Tirada furayaasha; `dherer(obj)` sidoo kale waa sax |
| `leeyahay(key)` | Hubi jiritaanka furaha |
| `hel(key, default?)` | Soo celi qiimaha ama beddelkiisa |
| `dhig(key, value)` | Qor qiime, soo celi isla walaxda |
| `saar(key)` | Ka saar oo soo celi qiimaha; `maran` haddii fure maqan yahay |
| `nadiifi()` | Ka saar dhammaan furayaasha, soo celi isla walaxda |
| `nuqul()` | Soo celi nuqul aan qoto dheerayn |
| `midee(other)` | Soo celi walax cusub oo isku darsan |

<SoplangCodeWindow title="objects_mutation.sop" code={`door qof = {magac: "Ayaan", da: 25}
qof.dhig("da", 26)
qor(qof.saar("da"))          // 26
qor(qof.leeyahay("da"))      // been
qor(qof.saar("maqan"))       // maran`}/>

Magacii hore `tir(key)` weli waa la taageeraa, laakiin wuxuu soo celiyaa
walaxda lafteeda. `saar(key)` wuxuu soo celiyaa qiimaha laga saaray.

## Furayaasha, qiimayaasha iyo lammaanayaasha

`furayaal()`, `qiimayaal()` iyo `lammaanayaal()` dhammaantood waxay raacaan
kala horraynta furayaasha ee la kala habeeyey.

<SoplangCodeWindow title="objects_entries.sop" code={`door qof = {magac: "Ayaan", da: 25}
qor(qof.furayaal())          // [da, magac]
qor(qof.qiimayaal())         // [25, Ayaan]
qor(qof.lammaanayaal())      // [[da, 25], [magac, Ayaan]]`}/>

## Isku darid iyo nuqul

`midee()` ma beddelo labada walxood ee la siiyey. Fure isku mid ah wuxuu
qaataa qiimaha walaxda midigta. Nuqulku ma aha mid qoto dheer; ururinta gudaha
ku jirta weli waa lala wadaagaa asalka.

<SoplangCodeWindow title="objects_merge.sop" code={`door asal = {magac: "Ayaan", da: 25}
door natiijo = asal.midee({da: 26, magaalo: "Hargeysa"})
qor(asal.da)                 // 25
qor(natiijo.da)                // 26
qor(natiijo.magaalo)           // Hargeysa`}/>

Objects ma laha `hore()` ama `dambe()`. Hababkaas waxay khuseeyaan liisaska
iyo strings-ka. Eeg [tixraaca](/docs/14_keywords-reference#object-methods).
