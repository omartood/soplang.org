### Operator Precedence

Operators have the following precedence, from highest to lowest:

1. Unary: `!`, `-`
2. `*`, `/`, `%`
3. `+`, `-`
4. Comparison: `==`, `!=`, `>`, `<`, `>=`, `<=`
5. Logical: `&&`, `||`

<Callout type="warn" title="&& and || have equal precedence">
  Many languages give `&&` higher precedence than `||`. In Soplang, both have equal precedence and group from left to right: `run || been && been` evaluates to `been`. Use parentheses when combining them, such as `run || (been && been)`.
</Callout>

## String Concatenation

`+` also joins strings. When either operand is a string, the other value, such as a number, boolean, or list, is converted to text.

<SoplangCodeWindow title="string_concat.sop" code={`qor("Soplang " + "waa fiican")   // Soplang waa fiican
qor("Da'da: " + 25)               // Da'da: 25

// Store the result of a comparison
door natiijo = 5 > 3
qor(natiijo)                      // run`}/>

Division (`/`) can produce a fractional result: `10 / 4` is `2.5`. Division by zero (`x / 0`) produces a runtime error.
