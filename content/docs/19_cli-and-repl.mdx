# Soplang CLI & REPL

The `soplang` command runs `.sop` files, opens an interactive shell (REPL),
and builds standalone executables.

## Running a File

```bash
soplang hello.sop
```

The Cranelift JIT compiles the program and runs it immediately.

## The REPL

Run `soplang` without arguments to open the REPL. Its startup banner and help
output are in Somali:

```text
$ soplang
Soplang 3.0.0 — Luuqadda barnaamijka ee Soomaaliyeed.
  /caawi  = caawimo   /bixi = bixi   /akhrifayl <fayl> = akhri oo orod
  Ctrl+D ama /bixi = bixi
```

| Command | Meaning |
| --- | --- |
| `/caawi` or `/help` | Show help |
| `/akhrifayl <file>` | Read and run a `.sop` file |
| `/ast` | Show the AST |
| `/hir` | Show the HIR |
| `/bixi`, `/exit`, or `Ctrl+D` | Exit the REPL |

Entering an expression such as `1 + 2` displays its result automatically.

To run a file and then continue in the REPL with its variables available, use `-i`:

```bash
soplang -i hello.sop
```

## Run a Snippet – `-c`

```bash
soplang -c 'qor("Salaan!")'
soplang -c '2 + 3'        # 5
```

## Build a Standalone Binary – `--build`

`--build` emits LLVM IR, then uses clang and rustc to link an ahead-of-time
(AOT) executable. The resulting program runs without a Soplang installation:

```bash
soplang --build hello.sop -o hello
./hello
```

| Option | Meaning |
| --- | --- |
| `-o, --output <file>` | Set the output executable's name |
| `--opt-level <0-3>` | Set the optimization level (default: `2`) |
| `-q, --quiet` | Hide the build message |

<Callout title="Native build toolchain">
  Official v3.0.0 packages require Rust 1.94.0, clang 15+, and the platform linker/SDK for `--build`. Keep the complete package together. Installed `--build` does not invoke Cargo. JIT execution and the REPL need neither Rust nor clang. See the [installation guide](/docs/00_installation#building-standalone-programs).
</Callout>

## Strict Mode – `--strict`

`--strict` rejects dynamic `door` declarations. Variables must have explicit
types, such as `abn`, `jajab`, `qoraal`, `bool`, `teed`, or `walax`.

```bash
soplang --strict app.sop
```

For example, an untyped declaration produces this Somali diagnostic:

```text
Khalad nooc: 'x' waa dynamic laakiin 'strict mode' waa shidan yahay [E022] safka 1, tiirka 1
```

## All Options

| Option | Meaning |
| --- | --- |
| `soplang <file>` | Run a file |
| `soplang` | Open the REPL |
| `-i, --interactive` | Run a file, then open the REPL |
| `-c, --command <code>` | Run a code snippet |
| `-f, --file <file>` | Run a file |
| `--build` | Build an AOT executable; requires a source file |
| `-o, --output <file>` | Set the output executable's name (`--build`) |
| `--opt-level <0-3>` | Set the optimization level (`--build`) |
| `-q, --quiet` | Hide the build message (`--build`) |
| `--strict` | Require static typing |
| `--ast` | Print the AST instead of executing the program |
| `--hir` | Print the HIR (intermediate representation) instead of executing the program |
| `--no-color` | Disable diagnostic colors; also supported through `NO_COLOR=1` |
| `-V, --version` | Show the version |
| `-h, --help` | Show help |
