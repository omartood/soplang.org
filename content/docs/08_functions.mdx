# Functions in Soplang

Functions (hawlo) waa qaybo koodh oo dib loo isticmaali karo. Soplang waxa lagu qeexaa `hawl` waxaana natiijo lagu soo celinayaa `celi`.

## Define a Function – `hawl`

Hawl waxa ay bilaabataa `hawl` kadibna magac hawl iyo parameters. Parameters-ku waxay noqon karaan dynamic ama typed (eeg hoos).

<SoplangCodeWindow title="define_function.sop" code={`hawl salaan(magac) {
    qor("Asalaamu calaykum, " + magac)
}`}/>

## Call a Function

Marka aad qeexdo, ku wac magaceeda oo raaci doodaha (arguments):

<SoplangCodeWindow title="call_function.sop" code={`hawl salaan(magac) {
    qor("Asalaamu calaykum, " + magac)
}
salaan("Aamina")`}/>

## Return Values – `celi`

Adeegso `celi` si aad uga soo celiso hawl qiime.

<SoplangCodeWindow title="return_values.sop" code={`hawl labanlaab(x) {
    celi x * 2
}

abn natiijo = labanlaab(5)
qor("Natiijo: " + natiijo)`}/>

Hawl aan `celi` lahayn — ama `celi` aan qiime lahayn — waxay soo celisaa `maran` (`maran`). `celi` bannaan waxaa loo isticmaali karaa in hawsha si degdeg ah looga baxo:

<SoplangCodeWindow title="early_return.sop" code={`hawl hubi(x) {
    haddii (x < 0) {
        qor("Tiro taban")
        celi
    }
    qor("Tiro togan")
}

hubi(-1)   // Tiro taban
hubi(3)    // Tiro togan`}/>

## Typed Parameters and Return Types

Waxaad nooc u qori kartaa parameter kasta, iyo nooca celinta adigoo `: nooc` ku daraya `)` kadib. Noocyada la yaqaan waxaa hubiya falanqaynta; qiimayaasha dynamic-ka ahna waxaa la hubiyaa xilliga fulinta.

<SoplangCodeWindow title="typed_functions.sop" code={`hawl isu_gee(abn a, abn b): abn {
    celi a + b
}

hawl magac_buuxa(qoraal hore, qoraal dambe): qoraal {
    celi hore + " " + dambe
}

qor(isu_gee(2, 3))                  // 5
qor(magac_buuxa("Aamina", "Cali"))  // Aamina Cali`}/>

Nooc khaldan oo la yaqaan waxaa la diidaa inta falanqayntu socoto:

<SoplangCodeWindow title="typed_functions_error.sop" code={`hawl isu_gee(abn a, abn b): abn { celi a + b }
isu_gee("2", 3)   // Khalad nooc: doodda 1 ee 'isu_gee' waa 'abn', laakiin 'qoraal' ayaa la helay [E022]`}/>

## Recursion

Hawl way wici kartaa nafteeda:

<SoplangCodeWindow title="recursion.sop" code={`hawl fiibo(n) {
    haddii (n < 2) {
        celi n
    }
    celi fiibo(n - 1) + fiibo(n - 2)
}

qor(fiibo(10))   // 55`}/>

## Functions as Values

Hawluhu waa qiimayaal (`nooc()` waxay soo celisaa `"hawl"`). Waxaad ku kaydin kartaa doorsoome, ama u gudbin kartaa hawl kale sida `aaddin()` iyo `shaandhee()` — magaca hawsha qaansooyin la'aan iyo xarfo-xigasho la'aan.

<SoplangCodeWindow title="functions_as_values.sop" code={`hawl laban(x) {
    celi x * 2
}

door f = laban
qor(f(21))                     // 42
qor([1, 2, 3].aaddin(laban))   // [2, 4, 6]`}/>

## Scope

Doorsoomayaasha lagu qeexo gudaha hawl waa maxali (local). Hawluhu waxay akhriyaan qiimaha hadda ee doorsoomayaasha guud (globals), waxayna beddeli karaan qiimayaashaas. Parameters iyo doorsoomayaal maxali ah waxay qariyaan magacyada guud ee isku magaca ah.

<SoplangCodeWindow title="scope.sop" code={`door tirin = 0

hawl kordhi() {
    tirin = tirin + 1
}

kordhi()
kordhi()
qor(tirin)   // 2`}/>

## Loops Inside Functions

Hawluhu waxay ka kooban karaan loops iyo logic kale sida blocks-ka caadiga ah.

<SoplangCodeWindow title="loops_inside_functions.sop" code={`hawl muujin(liis) {
    kuceli (i 0 ilaa liis.dherer() - 1) {
        qor("Liiska: " + liis[i])
    }
}`}/>

## Anonymous functions and closures

`hawl(...) { ... }` waa hawl aan magac lahayn. Waxay xafidi kartaa qiime
maxali ah oo ka yimid hawsha ku hareeraysan:

<SoplangCodeWindow title="closures.sop" code={`hawl samee(factor) {
    celi hawl(x) { celi x * factor }
}

door laban = samee(2)
qor([1, 2, 3].aaddin(laban))   // [2, 4, 6]`}/>

Captured local values use snapshot semantics when the closure is created.
Global variables are read from their current shared value. Callback methods
validate that their argument is callable, including for empty lists. Argument
counts are checked for functions, methods, closures, built-ins and constructors.

The compiled call boundary accepts eight ABI values, including implicit receiver
or closure environment arguments. Defaults, keyword arguments, variadic user
functions and arbitrary callable expressions remain planned work.
