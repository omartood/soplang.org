# Type Conversion in Soplang

Soplang waxa uu leeyahay shaqooyin-dhexdeed (built-ins) oo fudud oo lagu kala beddelo noocyada xogta. Kuwaas waxay kuu oggolaanayaan inaad si ammaan ah ugu beddesho u dhaxeysa integer, string, decimal, iyo boolean—adigoo ilaalinaya saxnaanta xogta.

## `nooc()` – Type Checking

Adeegso `nooc()` si aad u hubiso nooca qiime kasta.

**type_checking.sop**

<SoplangCodeWindow title="type_checking.sop" code={`door natiijo = nooc(42)         // "abn"

## `bool()` Rules

`bool()` waxay soo celisaa `been` qiimayaashan: `0`, `0.0`, `""`, `null`, `been`, liis madhan `[]`, object madhan `{}`, iyo qoraallada `"false"` ama `"False"`. Wax kasta oo kale waa `run` — xitaa qoraalka `"been"`.

<SoplangCodeWindow title="bool_rules.sop" code={`qor(bool(0))          // been
qor(bool(""))         // been
qor(bool([]))         // been
qor(bool("false"))    // been
qor(bool("salaan"))   // run
qor(bool("been"))     // run`}/>

## Example

<SoplangCodeWindow title="type_conversion_example.sop" code={`// Integer to string
abn int_value = 42
qoraal int_str = qoraal(int_value)
qor("Integer to string: " + int_str + " (Type: " + nooc(int_str) + ")")

// String to decimal
qoraal decimal_string = "3.14159"
jajab converted_decimal = jajab(decimal_string)
qor("String to decimal: " + converted_decimal + " (Type: " + nooc(converted_decimal) + ")")

// Decimal to integer (truncation)
jajab decimal_num = 42.75
abn int_from_decimal = abn(decimal_num)
qor("Decimal to integer (truncation): " + int_from_decimal)`}/>

Shaqooyinkan beddelka noocyadu waxay muhiim u yihiin dhismaha _input-handling_ adag, tusaale ahaan marka aad akhrinayso gelinta isticmaalaha ama faylasha oo aad rabto inaad hubiso noocyo sax ah ka hor inta aanad xisaab samayn.
