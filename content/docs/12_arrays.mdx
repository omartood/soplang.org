Liis (`teed`) waa ururin qiimayaal ah oo kala horraysa. Qiimayaashu waxay yeelan karaan noocyo kala duwan. `teed` waa nooca la qoro, `door`-na wuxuu qaadan karaa liis dynamic ah.

## Abuuridda iyo akhrinta liiska

<SoplangCodeWindow title="lists_lookup.sop" code={`teed tirooyin = [10, 20, 30]
qor(tirooyin.dherer())     // 3
qor(tirooyin[0])           // 10
qor(tirooyin[-1])          // 30
qor(tirooyin.hore())       // 10
qor(tirooyin.dambe())      // 30
qor(tirooyin.hel(9, 0))    // 0`}/>

Index-ku wuxuu ka bilaabmaa `0`; index taban wuxuu ka tiriyaa dhammaadka.
Akhrin ka baxsan liiska waxay soo celisaa `maran`. `hel(index, default?)`
wuxuu soo celiyaa qiimaha beddelka ah marka booska la waayo. Qiime `maran`
ah oo liiska ku jira lama beddelo. `hore()` iyo `dambe()` waxay liis madhan
ka soo celiyaan `maran`.

## Wax ku darid, beddelid iyo saarid

| Habka | Shaqada |
| --- | --- |
| `geli(value)` | Ku dar hal qiime dhammaadka liiska, xitaa haddii qiimuhu yahay liis kale |
| `geli(index, value)` | Geli hal qiime boos la cayimay |
| `dhig(index, value)` | Beddel boos jira; ma abuuro boos cusub |
| `saar()` | Ka saar oo soo celi qiimaha ugu dambeeya |
| `saar(index)` | Ka saar oo soo celi qiimaha booskaas |
| `nadiifi()` | Ka saar dhammaan qiimayaasha |

<SoplangCodeWindow title="lists_mutation.sop" code={`door tirooyin = [10, 20]
tirooyin.geli(30)
tirooyin.dhig(0, 5)
qor(tirooyin.saar(1))     // 20
qor(tirooyin)             // [5, 30]
tirooyin.geli([40, 50])
qor(tirooyin)             // [5, 30, [40, 50]]`}/>

`saar()` ee liis madhan iyo qorista boos aan jirin waa khaladaad la qaban
karo. Hababka kale ee liiska beddela waxay soo celiyaan isla liiska.

## Isku darid iyo nuqul

`midee(other)` wuxuu soo celiyaa **liis cusub**. `nuqul()` iyo `jar()` sidoo
kale waxay abuuraan liisas cusub. Kuwani waa nuqullo aan qoto dheerayn:
liis ama walax gudaha ku jira weli waa lala wadaagaa asalka.

<SoplangCodeWindow title="lists_copy.sop" code={`door asal = [10, 20, 30]
door natiijo = asal.midee([40])
qor(asal)                 // [10, 20, 30]
qor(natiijo)                // [10, 20, 30, 40]
qor(asal.jar(1, 3))       // [20, 30]
qor(asal.jar(-2))         // [20, 30]`}/>

Xadka dambe ee `jar(start?, end?)` kuma jiro natiijada. Xadadku waa tirooyin
dhan, waxaa lagu xaddidaa dhererka liiska, xadad is rogayna waxay keenaan
liis madhan. `jar()` wuxuu nuqul ka sameeyaa liiska oo dhan.

## Raadin, tirin iyo kala habayn

| Habka | Natiijada |
| --- | --- |
| `leeyahay(value)` | `run` haddii qiimuhu jiro |
| `raadi(value)` | Index-ka koowaad, ama `maran` marka la waayo |
| `tiri(value)` | Tirada qiimayaasha la midka ah |
| `rog()` | Rog kala horraynta liiska laftiisa |
| `habee()` | U kala hormari qiimayaasha liiska laftiisa |

<SoplangCodeWindow title="lists_sort.sop" code={`door tirooyin = [10, 2, 3, 2]
tirooyin.habee()
qor(tirooyin)             // [2, 2, 3, 10]
qor(tirooyin.raadi(2))    // 0
qor(tirooyin.raadi(99))   // maran
qor(tirooyin.tiri(2))     // 2`}/>

Tirooyinka waxaa loo kala hormariyaa tiro ahaan. Liis ka kooban noocyo isku
dhafan wuxuu isticmaalaa isbarbardhigga runtime-ka; ha ku tiirsanaan inuu noqdo
kala horrayn af-Soomaali ama kala horrayn tiro oo isku nooc ah. Raadin guulaysata
waxay soo celin kartaa `0`, sidaa darteed si cad u hubi `maran` markaad raadinayso
qiime maqan. Isbarbardhigga ururintu wuxuu kala saaraa `abn` iyo `jajab`.

## Hawlaha callback-ka

| Habka | Shaqada |
| --- | --- |
| `aaddin(callback)` | U beddel qiime kasta, soo celi liis cusub |
| `shaandhee(callback)` | Soo celi qiimayaasha buuxiya shuruudda |
| `ururi(callback, initial)` | Isku ururi bidix ilaa midig; callback-ku wuxuu helaa natiijada iyo qiimaha xiga |
| `dhammaan(callback)` | Hubi in dhammaan qiimayaashu shuruudda buuxiyaan |
| `qaar(callback)` | Hubi in ugu yaraan hal qiime shuruudda buuxiyo |

<SoplangCodeWindow title="lists_callbacks.sop" code={`door tirooyin = [1, 2, 3, 4]
qor(tirooyin.aaddin(hawl(x) { celi x * 2 }))       // [2, 4, 6, 8]
qor(tirooyin.shaandhee(hawl(x) { celi x % 2 == 0 })) // [2, 4]
qor(tirooyin.ururi(hawl(a, b) { celi a * b }, 1)) // 24
qor(tirooyin.dhammaan(hawl(x) { celi x > 0 }))    // run
qor(tirooyin.qaar(hawl(x) { celi x > 3 }))        // run`}/>

Ku-celcelintu waxay isticmaashaa nuqul aan qoto dheerayn oo laga qaaday
liiska markii la bilaabay. Callback-ku wuu beddeli karaa liiska asalka ah;
qiimayaashii ku-celcelintu raacaysay isma beddelaan. Khalad callback ah wuxuu
joojiyaa hawsha oo u gudbaa `qabo`. `dhammaan()` iyo `qaar()` waxay joojiyaan
marka natiijadu caddaato; liis madhan waxay ka soo celiyaan `run` iyo `been`.

Magacyadii hore ee la taageero iyo kala duwanaanshaha `kudar()` waxaa lagu
sharaxay [tixraaca](/docs/14_keywords-reference#compatibility-spellings).
