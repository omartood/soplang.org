# Loops in Soplang

Soplang waxa uu taageeraa laba nooc oo loops ah: `intay (shuruud)` oo u dhiganta _while_, iyo `kuceli (bilow ilaa dhamaad)` oo u dhiganta _for_. Waxa kale oo jira `jooji` (break) iyo `soco` (continue) si aad u yeelato xakameyn faahfaahsan.

## While Loop – `intay`

Koodhka ku jira block-ga wuu soconayaa inta shuruuddu tahay _run_:

**while_basic.sop**

<SoplangCodeWindow title="while_basic.sop" code={`abn i = 1
intay (i <= 5) {
    qor("i = " + i)
    i = i + 1
}`}/>

Waxay taageertaa `jooji` iyo `soco`:

**while_break_continue.sop**

<SoplangCodeWindow title="while_break_continue.sop" code={`abn i = 0
intay (i <= 10) {
    i = i + 1

    haddii (i % 2 == 0) {
        soco        // ka bood tirooyinka labiska ah
    }

    haddii (i == 7) {
        jooji        // jooji loop-ka marka i = 7
    }

    qor("i = " + i) // waxay daabacdaa: 1, 3, 5
}`}/>

## For Loop – `kuceli`

Qaabka guud waa `kuceli (doorsoome bilow ilaa dhamaad :: talaabo)`. Xadka waa **inclusive** — `dhamaad` laftiisa waa la gaaraa. `:: talaabo` waa ikhtiyaari (default waa `1`).

**for_basic.sop**

<SoplangCodeWindow title="for_basic.sop" code={`kuceli (i 1 ilaa 5) {
    qor("Tirada: " + i)
}`}/>

Talaabo (step) la doortay:

**for_step.sop**

<SoplangCodeWindow title="for_step.sop" code={`kuceli (j 2 ilaa 10 :: 2) {
    qor("Step: " + j)
}`}/>

<Callout type="warn" title="Talaabo taban (negative step)">
  Hadda `kuceli` wuxuu u socdaa kor oo keliya — `kuceli (i 5 ilaa 1 :: -1)` waxba ma fuliyo. Si aad hoos ugu tiriso, isticmaal `intay`.
</Callout>

**count_down.sop**

<SoplangCodeWindow title="count_down.sop" code={`door i = 5
intay (i >= 1) {
    qor(i)
    i = i - 1
}`}/>

`ilaa` ma aha keyword la xafiday; waxay macno leedahay oo keliya gudaha `kuceli (...)`.

## Loop Over List

**loop_over_list.sop**

<SoplangCodeWindow title="loop_over_list.sop" code={`teed numbers = [10, 20, 30]
kuceli (i 0 ilaa numbers.dherer() - 1) {
    qor("Element " + i + ": " + numbers[i])
}`}/>

## Range with `baaxad()`

`baaxad()` waxay soo saartaa liis tirooyin ah (sida Python `range`). Dhamaadku **kuma jiro** liiska.

<SoplangCodeWindow title="baaxad_range.sop" code={`qor(baaxad(5))          // [0, 1, 2, 3, 4]
qor(baaxad(2, 6))       // [2, 3, 4, 5]
qor(baaxad(1, 10, 2))   // [1, 3, 5, 7, 9]`}/>

## Nested Loops

**nested_loops.sop**

<SoplangCodeWindow title="nested_loops.sop" code={`kuceli (i 1 ilaa 3) {
    intay (i > 0) {
        qor("Nested example")
        jooji
    }
}`}/>

## Factorial with While

**factorial_while.sop**

<SoplangCodeWindow title="factorial_while.sop" code={`abn a = 5
abn result = 1
abn n = a

intay (n > 0) {
    result = result * n
    n = n - 1
}
qor(result)`}/>
