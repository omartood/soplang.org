# Error Handling in Soplang

Marka khalad runtime ah dhaco (tusaale qaybinta eber), barnaamijku wuu joogsadaa. Si aad u qabato khaladka oo barnaamijku u sii socdo, isticmaal `tijaabi` iyo `qabo`.

## `tijaabi` iyo `qabo` – Try / Catch

Koodhka khatarta leh geli block-ga `tijaabi`. Haddii khalad dhaco, fulintu waxay u boodaysaa block-ga `qabo`, fariinta khaladkana (`qoraal`) waxaa lagu kaydiyaa doorsoomaha ku jira `qabo (...)`.

<SoplangCodeWindow title="try_catch.sop" code={`hawl qaybi(a, b) {
    celi a / b
}

tijaabi {
    qor(qaybi(10, 2))      // 5
    qor(qaybi(10, 0))      // khalad: waxay u boodaysaa qabo
    qor("Tan lama gaaro")
} qabo (khalad) {
    qor("Qabtay: " + khalad)   // Qabtay: Tiro looma qaybin karo eber.
    qor(nooc(khalad))          // qoraal
}

qor("Barnaamijku wuu sii socdaa")`}/>

- `qabo` waa qasab — `tijaabi` mar walba waa inuu leeyahay `qabo (magac)`.
- Haddii aan khalad dhicin, block-ga `qabo` lama fuliyo.
- `tijaabi` waa la isku dhex dhigi karaa (nest). Khaladka waxaa qabanaya `qabo`-ga ugu dhow.

<SoplangCodeWindow title="nested_try.sop" code={`tijaabi {
    tijaabi {
        qor(1 / 0)
    } qabo (gudaha) {
        qor("gudaha: " + gudaha)
    }
    qor("kadib")
} qabo (dibadda) {
    qor("dibadda")
}`}/>

<Callout title="Khaladaadka methods-ka">
  `tijaabi` wuxuu qabtaa khaladaadka runtime-ka ee hawlaha ku-dhexjira, methods-ka, callbacks-ka iyo qaybinta eber. Khalad callback ah wuxuu joojiyaa ku-celcelinta, wuxuuna u gudbaa `qabo`-ga ugu dhow. Khaladaadka lexer-ka, parser-ka iyo falanqaynta waxay dhacaan ka hor fulinta.
</Callout>

## Signalling Failure from a Function

Soplang ma laha keyword `throw`. Si hawl u sheegto in ay fashilantay, inta badan waxaa la soo celiyaa `maran` kadibna waa la hubiyaa:

<SoplangCodeWindow title="return_maran.sop" code={`hawl hubi_da(da) {
    haddii (da < 0) {
        celi maran
    }
    celi da
}

door natiijo = hubi_da(-5)
haddii (natiijo == maran) {
    qor("Da' khaldan")
}`}/>

## Error Messages

Fariimaha khaladka Soplang waxay ku qoran yihiin Af-Soomaali, waxayna leeyihiin qaabkan:

```text
Khalad <nooc>: <fariin> [<code>] safka <sadar>, tiirka <tiir>
     --> <fayl>:<sadar>:<tiir>
```

Tusaale, marka `madoor` la beddelo:

```text
Khalad nooc: Ma bedeli kartid qiimaha doorsamaha madoor 'luqad' [E020] safka 2, tiirka 1
     --> luqad.sop:2:1
   2 │   luqad = "English"
     │   ^^^^^
     └─ Doorsamaha madoor ma beddeli karaan qiimahooda. Isticmaal 'door' haddii aad rabto mid beddeli kara.
```

Noocyada khaladka (`<nooc>`):

| Nooc | Goorta uu dhaco |
| --- | --- |
| `ereyayn` | Xaraf aan la aqoon, string ama faallo aan la xirin |
| `naxwe` | Syntax khaldan, tusaale `)` ama `}` maqan |
| `nooc` | Nooc aan is-waafaqsanayn (type error) |
| `fulin` | Khalad inta barnaamijku socdo, tusaale qaybinta eber |
| `soo-dejin` | Fayl `keen` lagu sheegay oo aan la helin |

Colors-ka waxaa lagu dami karaa `--no-color` ama `NO_COLOR=1`.

## Error Codes

Khaladaadka qaarkood waxay wataan code gaaban oo kaa caawinaya inaad raadiso:

| Code | Macnaha |
| --- | --- |
| `E001` | Xaraf aan la filayn |
| `E002` | String aan la xirin |
| `E003` | Faallo `/* */` aan la xirin |
| `E020` | Dib-u-qeexid, ama beddelid doorsoome `madoor` ah |
| `E021` | Wax aan la helin, tusaale fayl `keen` lagu sheegay |
| `E022` | Nooc aan is-waafaqsanayn (static type, doodaha hawl, ama nooca celinta) |

## Source context and exit status

Uncaught failures write Somali diagnostics to stderr and exit with status 1.
Diagnostics include the source file, line, column, source line and caret. Columns
count Unicode scalar values; caret spacing accounts for tabs, combining marks
and wide characters. Imported files retain their own source context. LLVM-built
executables retain relevant source lines even when the original files are gone.
Caught errors are message strings, not structured error objects or stack traces.
`fasax` remains a compatible try spelling; new examples use `tijaabi`.
