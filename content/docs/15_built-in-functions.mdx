## Notes

- **`walax()`** waxay qaadataa lammaanayaal fure–qiime ah oo isku xiga: `walax("magac", "Ali", "da", 20)`. Inta badan waa ka fudud tahay in la qoro object literal: `{magac: "Ali", da: 20}`.
- **`dherer()`** waxay ka shaqaysaa strings, liisas, iyo objects. Liisaska, strings-ka iyo objects-ku sidoo kale waxay leeyihiin habka `.dherer()`.
- **`xul()`** waxay leedahay saddex qaab:
  - `xul()` — jajab random ah oo u dhexeeya `0` iyo `1`
  - `xul(a, b)` — jajab random ah oo u dhexeeya `a` iyo `b`. Haddii aad rabto tiro dhan, isticmaal `daji(xul(1, 7))` (`1`–`6`).
  - `xul(liis)` — hal walax oo random ah oo liiska ka mid ah
- **`baaxad()`** waxay soo saartaa liis tirooyin ah; dhamaadku kuma jiro: `baaxad(5)` → `[0, 1, 2, 3, 4]`, `baaxad(2, 6)` → `[2, 3, 4, 5]`, `baaxad(1, 10, 2)` → `[1, 3, 5, 7, 9]`.
- **`daji()` / `kor()`** waxay soo celiyaan `abn`.

## Examples

**builtins_examples.sop**

<SoplangCodeWindow title="builtins_examples.sop" code={`// Output
qor("Hello World")

// Input
door magac = gelin("Magacaaga geli: ")
qor("Magacaaga waa: " + magac)

// Type detection
door t = nooc(5)
qor("Type: " + t)

// Conversion
door a = abn("42")
door f = jajab("3.14")
door s = qoraal(100)
door b = bool(0)

// List and Object creation
door l = teed(1, 2, 3)
door o = walax("name", "Ayaan", "age", 20)

// Math rounding
qor("Floor: " + daji(4.8))
qor("Ceil: " + kor(4.2))

// Random number
door r = daji(xul(1, 7))
qor("Random: " + r)

// Random item and range
qor(xul(["Cas", "Buluug", "Cagaar"]))
qor(baaxad(1, 5))   // [1, 2, 3, 4]`}/>

**Gunaanad:** built-ins-ka Soplang waxay ka dhigaan koodhka mid kooban, muujin leh, isla markaana si dabiici ah ugu qoran Af-Soomaali.

## Numeric helpers in Soplang 3

| Hawsha | Shaqada | Tusaale |
| --- | --- | --- |
| `duub(x)` | U soo koob integer-ka ugu dhow; kala-bar wuxuu ka fogaadaa eber | `duub(-2.5)` waa `-3` |
| `sugan(x)` | Qiimaha aan tabanayn (absolute value) | `sugan(-5)` waa `5` |
| `yar(...)` | Qiimaha ugu yar ee doodaha tirooyinka ah | `yar(4, 2, 8)` waa `2` |
| `weyn(...)` | Qiimaha ugu weyn ee doodaha tirooyinka ah | `weyn(4, 2, 8)` waa `8` |
| `jibbaar(a, b)` | Kor-u-qaad awood | `jibbaar(2, 3)` waa `8` |
| `xidid(x)` | Xididka laba-jibbaaran | `xidid(9)` waa `3` |

keliya; tallaabo eber ah waa khalad. Tirada doodaha hawl kasta waa la hubiyaa.
